# Quay Cảnh

App Android: đứng trước cảnh đẹp, mở app quay một đoạn. AI xem cảnh, chọn đoạn văn hợp (trong Kho văn
hoặc tự viết), chọn nhạc nền, đọc bằng giọng VieNeu-TTS / OmniVoice, rồi xuất video có phụ đề chạy chữ.

- Tải APK: mục **Releases** (bản mới nhất) → `QuayCanh.apk`.
- Cài đặt trong app: dán khóa Gemini (miễn phí tại aistudio.google.com/apikey) hoặc khóa Claude.
- Kho văn: dán các trích đoạn tiểu thuyết anh thích; mỗi đoạn cách nhau một dòng trống,
  dòng `— Tác phẩm, Tác giả` là nguồn, dòng `# biển, chiều` là thẻ.
- Nhạc: 4 bản nhạc nền có sẵn, hoặc chọn thư mục nhạc trên máy (đặt tên file dễ hiểu để AI chọn).
